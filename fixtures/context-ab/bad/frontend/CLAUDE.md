# Frontend rules

These rules apply to work in `frontend/`.

@./DESIGN.md

- Read [README.md](README.md), section "Design and display rules", before you change a component.
- Use `npm --prefix frontend run build` to check a change. There are no tests.
- Use the tokens in `src/styles/global.css`. Do not add raw colors in components.
- Do not change URLs, titles, H1, or intros before the 3 November reading.
- After a page change, add a row to its file in [../second-iteration/decisions/](../second-iteration/decisions/index.md).
