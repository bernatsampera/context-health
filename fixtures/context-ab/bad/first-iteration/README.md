# First iteration (27 August to 11 October 2026)

This folder is the archive of the first iteration. Nothing here is a current instruction.
Read a file here only when a decision file in `second-iteration/decisions/` points to it.

- `docs/`: the session journal (`NOW.md`), the product and money review, the public wording plan, the search page plan, and the TikTok post-mortem.
- `seo/`: three SEO plans (ten work areas, the improvement plan, the hard-truths plan) and the outreach plan.
- `frontend/`: the early SEO notes for the Astro site (`SEO-NOTES.md`).
- `revision/`: quick country reviews for 41 countries, Europe patterns, the Baltic comparison, and the shared local group update.
- `experiments/`: calibration, category signal, sample size curve, LLM name classification, product discovery, and frontend design probes.
- `archive/`: material closed before September 2026 (grove, handoffs, pre-v5, old probes).
- `context/`: the gcontext seed files.
- `design_handoff_*`: the map and TikTok design handoffs.
- `wireframes-*.html`, `run_places_batch.sh`, `places_batch_*`: early wireframes and the places batch script with its logs.
- `pipeline/`: code removed from `pipeline/` on 2026-10-18 (B1), at the same relative paths: evaluation, research, show walkthroughs, tests, the artifact migration tool and its notes, the unified status script, and the factory admin UI with its two services.
