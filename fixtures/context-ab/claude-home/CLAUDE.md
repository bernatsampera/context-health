# Global instructions

## Writing

- Write short sentences in active voice.
- Use one instruction for each sentence.
- Do not use en dashes or em dashes. Use a comma, a colon, or a plain hyphen.

## Tools

- Use `uv run` for Python. Do not use pip.
- Do not delete files. Move them to the Trash.

## Tests

- Prefer end-to-end tests. Do not write unit tests after the code.
- At the end of an end-to-end test, keep a repeatable artifact as proof.

## Skills

- Before you write prose, apply the `@~/.claude/skills/unslop/SKILL.md` rules. This is a code span, not an import.
